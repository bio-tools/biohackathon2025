# Security policy

## Supported versions

Only the latest release of `metadata-bridge` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/bio-tools/metadata-bridge/security/advisories/new)
("Report a vulnerability" on the repository's Security tab).

Please include what you found, how to reproduce it, and the version or commit affected.
We'll acknowledge the report as soon as we can and keep you posted on the fix.

The tool handles GitHub and Hugging Face tokens: if you think a token may have been exposed,
revoke it with the provider right away.
